Hallazgos visuales y funcionales
El levantamiento se concentró en lo que un usuario puede ver y hacer públicamente en Invierte360. A
continuación se expone la evidencia visual y su respectivo análisis.
1. Home: el recorrido debe terminar en una acción verificable
EVIDENCIA
CTA/anchor observado en el
levantamiento; revalidar estado.
IMPACTO
Una interrupción puede desperdiciar
intención.
MEJORA
CTA por intención + destino funcional.
2. Filtros: necesitan más certeza de interacción
ACTUAL
Catálogo y filtros operativos.
FRICCIÓN
Actualización / Aplicar puede sentirse
redundante.
MEJORA
Una lógica clara + feedback + resultados.

3. Formulario: éxito visual no equivale a contacto recibido
PRUEBA
La interfaz confirmó; se indicó no
recepción real.
RIESGO
Posible pérdida de contactos.
PENDIENTE
Validar Destinatario → SMTP → recepción
real.
4. WhatsApp: el contexto no es uniforme
FORTALEZA
Ficha individual puede precargar
proyecto.
BRECHA
Otros accesos entregan menos contexto.
MEJORA
Contexto = Proyecto + comuna + origen
+ URL.

5. Calculadora: intención de alto valor
FORTALEZA
Simulación con variables financieras
reales.
BRECHA
No continúa estructuradamente hacia
contacto.
MEJORA
Simulación → proyectos compatibles →
asesor.
6. Vendedor: intención distinta, recorrido distinto
ACTUAL
Deriva al contacto genérico.
PROBLEMA
Se mezcla vendedor con inversionista.
MEJORA
Landing + formulario específico para
venta.
